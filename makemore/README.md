## MakeMore
### bi-gram
A character-level bigram language model introducing the fundamentals of language modeling, including torch. Tensor operations, efficient neural network evaluation, model training, text generation through sampling, and loss evaluation using negative log-likelihood for classification. [Block](https://github.com/ali36saadat/micro-to-nano/blob/main/blocks/bigram.py) | [Video](https://youtu.be/PaCmpygFfXo)

### MLP
A multilayer perceptron (MLP) character-level language model covering fundamental machine learning concepts, including model training, learning rate tuning, hyperparameter selection, model evaluation, train/dev/test splits, and underfitting and overfitting. [Video](https://youtu.be/TCH_1BHY58I)


### MLP2
An exploration of deep MLP internals, focusing on forward activations, backward gradients, scaling issues, and diagnostic visualizations. Introduces Batch Normalization as a key technique for stabilizing deep neural network training. [Video](https://youtu.be/P6sfmUTpUmc)

### Backprob Ninja
A manual backpropagation walkthrough through a 2-layer MLP with Batch Normalization, covering gradient flow through the computational graph using efficient PyTorch Tensors. Develops intuition for neural network optimization and debugging. [Video](https://youtu.be/q8SA3rM6ckI)

### WaveNet
Extending a 2-layer MLP into a deeper, tree-like architecture inspired by WaveNet, introducing CNN fundamentals, exploring torch.nn internals, and demonstrating practical deep learning workflows, including tensor shape management and documentation-driven development. [Video](https://youtu.be/t3YJ5hKiMQ0)
