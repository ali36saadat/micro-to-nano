# Micro To Nano
[![Header](https://github.com/user-attachments/assets/8c906e4d-952e-4bb2-9180-fd68775675b8)](https://ali36saadat.github.io/repositories/micro-to-nano)

## Description
### MicroGrad
A minimal autograd implementing reverse-mode automatic differentiation over dynamically built DAGs, with scalar-based computation. Includes a lightweight neural network library with a PyTorch-like API, capable of building and training deep neural networks for binary classification. [Folder](https://github.com/ali36saadat/micro-to-nano/tree/main/micrograd)

### MakeMore
A character-level autoregressive language model that learns patterns from text and generates new, similar sequences. Supports models ranging from simple bigrams to Transformers, enabling applications such as generating names, words, and other text-like sequences. [Folder](https://github.com/ali36saadat/micro-to-nano/tree/main/makemore)

### GPT
A Generatively Pretrained Transformer (GPT), following the paper "Attention is All You Need" and OpenAI's GPT-2 / GPT-3. [Folder](https://github.com/ali36saadat/micro-to-nano/tree/main/gpt)
